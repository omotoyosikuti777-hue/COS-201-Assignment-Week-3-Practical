
# COS 201 Java Programming Assignment

## Description
This repository contains three Java programs developed for the COS 201 assignment.

## Programs

1. **SimpleCalculator.java**
   - Performs addition, subtraction, multiplication and division.

2. **AverageCalculator.java**
   - Calculates the average of three numbers.

3. **ItemCost.java**
   - Calculates the total cost of items using their price and quantity.

## Requirements
- Java Development Kit (JDK 8 or later).
- A Java-compatible IDE or terminal.

## How to Run

Compile each program:

```bash
javac SimpleCalculator.java
javac AverageCalculator.java
javac ItemCost.java
```

Run each program:

```bash
java SimpleCalculator
java AverageCalculator
java ItemCost
```
